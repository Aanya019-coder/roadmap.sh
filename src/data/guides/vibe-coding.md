# What is Vibe Coding?

Vibe Coding is a modern paradigm of software development where the developer focuses on orchestration, architecture, and prompting, while agentic AI handles the direct code generation and implementation details.

## Why it matters

- **Unprecedented Speed**: Build full web applications in minutes.
- **Accessibility**: Allows developers to prototype and validate ideas without getting bogged down in boilerplate code.
- **Focus on Business Logic**: Spend more time designing user experience and flow.
