# What is Claude Code?

Claude Code is a state-of-the-art agentic AI coding assistant designed to help developers build, test, and debug applications directly from their terminal. 

## Key Features

- **Terminal Integration**: Runs commands, edits files, and manages git branches directly.
- **Context Awareness**: Analyzes your entire codebase to provide highly relevant solutions.
- **Automated Refactoring**: Refactors large pieces of code following your project's design tokens.

## How to use Claude Code

1. Initialize the assistant in your project folder.
2. Ask questions about the codebase or request code modifications.
3. Review changes and run tests before committing.
