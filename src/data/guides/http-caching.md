# HTTP Caching

HTTP caching is one of the most effective ways to optimize web performance, reduce server load, and improve load times for users.

## Cache Headers

- **Cache-Control**: Specifies directives for caching mechanisms in both requests and responses.
- **ETag**: A unique identifier for a specific version of a resource.
- **Expires**: The date/time after which the response is considered stale.
- **Last-Modified**: The date and time the resource was last updated.
